# 趣味点餐 — 项目设计记忆

## 设计语言（2026-05-30确立）
- **品牌调性**: 温馨治愈 × 活力玩趣
- **品牌3词**: 活力 · 热情 · 玩趣
- **主色调**: 暖珊瑚 #F26B5E（代替原 #FF6B35）
- **页面底色**: #FEF8F5（暖白）
- **文字色**: #3D2C25（暖深棕）| #8C7A72（次要）| #B5A59C（占位）
- **点缀色**: #5BC0BE（玩趣青）| #F9D56E（玩趣黄）| #F7A9A8（玩趣粉）
- **设计文件**: UI-DESIGN-SYSTEM.md、.impeccable.md（root目录）

## 设计原则
1. 温暖的空白有力量
2. 趣味藏在细节里（微动效、俏皮文案）
3. 分层信息，一次一件事
4. 触感优先（≥44px触摸目标）
5. 色彩是情绪，不是装饰

## 代码约定
- CSS 变量定义在 app.wxss 中，所有样式文件引用变量而非硬编码
- 所有组件的接口（事件名、属性）保持不变，JS逻辑层无需修改
- 圆角 token: --radius-sm(12rpx) / md(16rpx) / lg(20rpx) / xl(24rpx) / full(999rpx)
